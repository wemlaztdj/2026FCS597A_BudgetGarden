# High-Fidelity Prototype of Budgeting App 
## Overview
**Budget Garden**

This is a high-fidelity prototype of a budgeting web app designed for college students. It uses a garden metaphor to make budgeting easier to understand and more engaging.

## How to Run the Prototype
**Android Studio is required to run and emulate this prototype. Please download it before following these steps at this link: https://developer.android.com/studio*

1. Download and open this repository in Android Studio or clone it in Android Studio.
2. Wait for Gradle to sync. You can check its sync progress at the bottom right of the screen. The first sync may take 5-10 minutes. If there is a pop-up asking you to trust the project, click the option to trust the project. 
3. Start a device emulator. At the top of the screen, click on the hamburger menu/three bars. Then, click on Tools and then Device Manager. Click Create Virtual Device, pick any phone, and click Next. Choose a system image and download it if needed. Then click Next and Finish. 
4. Go back to the Device Manager and select the emulator you just started. Make sure the configuration next to says app. Click the green Run button with a sideways triangle next to it. This build may take some time to download the app on the device emulator.
